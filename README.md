# Matrix Multiplication Optimization Based on HLS
for-loop를 입력값으로 하는 HLS DSE 제안

## <abstract>
기존 연구는 모델 학습 데이터 생성 시 덧셈 및 곱셈과 같은 기본 연산자의 자원 사용량 최적화에만 국한되어 있었으며, 실제 연구에서 빈번히 등장하는 반복문 최적화는 고려하지 않았다. 이에 본 연구에서는 다양한 알고리즘의 핵심 연산으로 활용되는 Matrix Multiplication을 대상으로 중첩 반복문 기반 코드의 자동 최
적화 기능을 확장하였다.
